# ANTON — Project Cleanup Manifest
## Log of Disposable Artifacts, Cleaned Caches, and Disposal Actions

**Manifest Date**: November 19, 2026  
**Status**: EXECUTED & VERIFIED  
**Auditor**: Antigravity Technical Lead & Software Architecture Team

## 1. Cleanup Policy & Verification Rules

In accordance with Section 3 of the Stage 3.0 requirements:
- **No protected user assets or designs were removed**: All antenna designs, canonical JSON geometries, STEP/STL models, generated notebooks, test fixtures, and documentation were strictly preserved.
- **No original pretrained checkpoints were touched**: All Category A weight files (`s11_model.pt`, `best_forward_surrogate.pt`, `saved-model-5000.h5`, etc.) remain intact and read-only.
- **Only demonstrably safe, regeneratable files were removed**: Target files consisted solely of compiled bytecode (`__pycache__`), ephemeral test caches (`.pytest_cache`), and editable installation metadata (`anton.egg-info`).

## 2. Itemized Cleanup Manifest

| Target Path | Category | Reason for Removal | Can Be Regenerated? | Recovery Method | Final Action |
|---|---|---|---|---|---|
| `src/anton/**/__pycache__/` | Bytecode Cache | Disposable CPython bytecode (`.pyc`) generated during execution. | Yes | Automatically recompiled by Python on module import. | **REMOVED** |
| `tests/**/__pycache__/` | Bytecode Cache | Disposable test bytecode (`.pyc`) generated during pytest runs. | Yes | Automatically recompiled by pytest on next run. | **REMOVED** |
| `.pytest_cache/` | Test Runner Cache | Ephemeral pytest session state (`nodeids`, `lastfailed`). | Yes | Automatically regenerated by pytest on invocation. | **REMOVED** |
| `src/anton.egg-info/` | Build Metadata | Ephemeral package metadata created during editable pip installation. | Yes | Regenerated via `pip install -e .` if required. | **REMOVED** |
| `backend/app/ml/external/` binary duplicates | Redundant Binaries | 8.8 MB duplicate copies of `.pt`, `.pth`, `.h5` files redundant with `src/anton/ml/external/`. | Yes | Single source of truth preserved in `src/anton/ml/external/`. | **REMOVED** |
